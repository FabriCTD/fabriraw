Política de privacidad

Vigente desde el 7 de noviembre de 2026.

Aviso: Este texto es una plantilla informativa y no constituye asesoramiento legal.

1. Resumen

  • El Sitio no usa cookies, ni propias ni de terceros.
  • El Sitio no usa analítica, píxeles de seguimiento, publicidad ni fuentes o scripts de terceros.
  • El Software funciona sin conexión y no envía fotos, metadatos, telemetría ni ningún otro dato.

2. Almacenamiento local en tu navegador

Si eliges el idioma inglés con el botón ES/EN, el Sitio guarda esa preferencia (clave fraw-lang) en el localStorage de tu navegador. Ese dato no sale de tu dispositivo, no te identifica y puedes borrarlo en cualquier momento desde la configuración del navegador. No es una cookie y no se envía al servidor.

3. Hosting: Netlify

El Sitio se aloja en Netlify, Inc. Como cualquier servidor web, la infraestructura de Netlify puede registrar datos técnicos de cada solicitud (por ejemplo, dirección IP, fecha y hora, URL solicitada, agente de usuario y código de respuesta) con fines de seguridad, prevención de abusos y operación del servicio. FabriCTD no usa esos registros para perfilar visitantes. El tratamiento que hace Netlify se rige por su política de privacidad.

4. Descargas y GitHub

Los archivos de descarga y el código fuente se sirven desde GitHub (GitHub, Inc.). Al descargar un archivo o visitar el repositorio, GitHub trata tus datos según su declaración de privacidad. Si abres un Issue, su contenido es público.

5. El Software

CTD Photo Studio y ctd-raw procesan tus archivos localmente, en tu equipo. No contienen telemetría ni necesitan conexión a internet para funcionar. Los metadatos de tus fotos (cámara, lente, fecha, número de serie, autor, etc.) se copian dentro del archivo .fraw que generas: tenlo en cuenta si compartes esos archivos.

6. Tus derechos

Como FabriCTD no recoge datos personales a través del Sitio ni del Software, en general no hay datos que consultar, rectificar o eliminar. Para ejercer derechos sobre los registros técnicos del hosting, consulta la política de Netlify.

7. Contacto

GitHub Issues del repositorio o Discord, usuario fabri.ctd.

Summary in English

This website uses no cookies, no analytics and no third-party scripts. Your language choice may be stored in your browser's localStorage only. Netlify, our host, may keep technical logs (such as IP addresses) for security — see the Netlify privacy policy. The software works offline and sends no data.
